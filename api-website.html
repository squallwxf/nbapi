NBAPI 接口文档

使用你的 NBAPI 令牌，以兼容 OpenAI、Claude 和 Gemini 的方式调用已开放模型。

API 接口地址https://nbapi.win/v1
OpenAI Compatible

余额按真实用量自动扣费

开始接入

先在“令牌管理”创建令牌。完整 Key 只在创建时显示，请将下面示例中的 `nb_sk_xxx` 替换为你的令牌。推荐使用 `X-NBAPI-Key`，也兼容 `Authorization: Bearer nb_sk_xxx`。

X-NBAPI-Key: nb_sk_xxx
Content-Type: application/json
Idempotency-Key: your-unique-request-id

OpenAI 对话

适用于 GPT 等 OpenAI 兼容对话模型。

curl https://nbapi.win/v1/chat/completions \
  -H "X-NBAPI-Key: nb_sk_xxx" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: chat-001" \
  -d '{"model":"gpt-5.5","messages":[{"role":"user","content":"你好"}],"max_tokens":256}'

Claude 对话

使用 Anthropic Messages 兼容格式。

curl https://nbapi.win/v1/messages \
  -H "X-NBAPI-Key: nb_sk_xxx" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: claude-001" \
  -d '{"model":"claude-sonnet-4-6","max_tokens":256,"messages":[{"role":"user","content":"你好"}]}'

Gemini 对话

使用 Gemini 原生 `v1beta` 格式。

curl "https://nbapi.win/v1beta/models/gemini-3.1-pro-preview:generateContent" \
  -H "X-NBAPI-Key: nb_sk_xxx" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: gemini-001" \
  -d '{"contents":[{"role":"user","parts":[{"text":"你好"}]}]}'

图片生成

异步接口：提交任务后查询任务状态。

curl https://nbapi.win/v1beta/models/T香蕉2:generateContent \
  -H "X-NBAPI-Key: nb_sk_xxx" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: image-001" \
  -d '{"contents":[{"role":"user","parts":[{"text":"生成一张城市夜景"}]}],"generationConfig":{"responseModalities":["TEXT","IMAGE"],"imageConfig":{"aspectRatio":"16:9","imageSize":"2K"}}}'

curl https://nbapi.win/v1/images/tasks/{task_id} \
  -H "X-NBAPI-Key: nb_sk_xxx"

视频生成

按模型系列使用对应的视频端点和参数。

curl https://nbapi.win/v1/videos \
  -H "X-NBAPI-Key: nb_sk_xxx" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: video-001" \
  -d '{"model":"veo-3.1-fast-1080","prompt":"城市夜景，电影感","aspect_ratio":"16:9","n":1}'

curl https://nbapi.win/v1/videos/{task_id} \
  -H "X-NBAPI-Key: nb_sk_xxx"

Codex / SDK 接入

OpenAI 兼容 SDK 可直接把 baseURL 指向 NBAPI，API Key 使用你创建的 NBAPI 令牌。

import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "nb_sk_xxx",
  baseURL: "https://nbapi.win/v1",
  defaultHeaders: {
    "X-NBAPI-Key": "nb_sk_xxx"
  }
});

const result = await client.chat.completions.create({
  model: "gpt-5.5",
  messages: [{ role: "user", content: "你好" }]
});

console.log(result.choices[0].message.content);

参数与计费

项目说明
接口地址OpenAI 兼容接口使用 `https://nbapi.win/v1`，Gemini 原生接口使用 `https://nbapi.win/v1beta`。
鉴权方式推荐传 `X-NBAPI-Key: nb_sk_xxx`；也兼容 `Authorization: Bearer nb_sk_xxx`。令牌归属哪个用户，就从哪个用户余额扣费。
输入/补全 Token按模型公开的输入、补全、缓存读取和缓存创建价格分别计算，单位为每 1M Token。动态模型会按上游返回的真实输入 Token 选择对应档位；NBAPI 只按真实 usage 结算。
图片/视频按模型设置的每次价格计费；异步任务失败或取消会自动退款。查询任务也需要携带自己的 NBAPI 令牌。
幂等键每次新调用必须传唯一 `Idempotency-Key`。重复使用同一个值会返回 `409 duplicate_idempotency_key`，避免上游重复扣费。
退款提示失败自动退款时，响应头会包含 `X-NBAPI-Refunded`、`X-NBAPI-Refunded-Amount`、`X-NBAPI-Balance`。
错误处理HTTP 4xx 表示请求、令牌或余额问题；HTTP 5xx 表示上游或服务异常，请根据 `error` 和 `requestId` 排查。
