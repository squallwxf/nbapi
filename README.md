# NBAPI

NBAPI 是一个 API 聚合网关项目，包含前端页面、后端服务、模型广场、令牌管理和计费逻辑。

## 当前能力

- 单一登录入口，登录后自动隐藏“登录”和“注册”
- 三层角色：主管理员、管理员、用户
- 管理员控制台：用户管理、渠道管理
- 用户管理：调整用户剩余额度、提升用户为管理员
- 渠道管理：维护上游接入网址和 API Key

## 本地项目

- 代码目录：`D:\nbapi`
- 前端页面：`api-website.html`
- 后端服务：`server.py`
- Nginx 配置：`nbapi.nginx`
- systemd 服务：`nbapi.service`

## 接力开箱

1. 先读 `项目接力说明.md` 和 `项目接力补充-2026-09-02.md`
2. 启动后端 `python server.py`
3. 启动静态页 `python -m http.server 8000 --bind 127.0.0.1`
4. 打开 `http://127.0.0.1:8000/api-website.html`
5. 先用 `admin / admin123` 验证登录、用户管理、渠道管理
6. 再用普通用户验证注册、令牌创建和完整 Key 复制

## 服务器上的项目

- 线上服务目录：`/opt/nbapi`
- 线上站点：`https://nbapi.win`
- 后端服务名：`nbapi`

## 更新方式

- 只改前端：更新 `api-website.html`，再上传到服务器
- 改后端：更新 `server.py`，上传后重启服务
- 改域名反代：更新 `nbapi.nginx`，重新加载 Nginx
- 上游 API Key：在站点的“系统设置”里配置，后端会保存在数据库中
- 本地完成后直接上传即可，不需要在服务器重新做一遍功能；如果改了数据库结构或数据，再做迁移或备份导入

## 重要说明

- `nbapi.sqlite3` 不要上传到 GitHub
- 这个数据库包含用户、令牌、余额、扣费记录和渠道密钥
- 如需迁移或备份，应该从服务器单独导出
